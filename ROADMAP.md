## 🎯 v1.1 - YouTube Comment Integration (NEXT)

**Status:** Planned (not started)
**Priority:** High
**Estimated effort:** Medium (2-3 days)

### Feature: Post Timestamped Timeline to YouTube Comments

After ending a game, users can click a "Post to YouTube" button to publish the event timeline as a comment on the current video. YouTube auto-links timestamps, making them clickable for viewers.

**Example comment output:**
```
🏀 Basketball Wizard Breakdown - vs Central High (2024-01-15)

0:15 - #23 Sam Cooper — 2PT Make
0:42 - #4 Alex Lee assisted #1 John Smith — 3PT Make
1:23 - #10 Taylor Jordan — Turnover
2:05 - Opp #14 scored — 2PT (Blown coverage: #23 Cooper)
3:18 - #15 Chris Brown — Defensive Rebound
4:52 - #1 John Smith — 3PT Make (+3: Team up 8-5)

Final Score: 45-42 W
Generated by Basketball Basketball Wizard Extension
```

**Why this matters:**
- Transforms private film study into shareable content
- Coaches can post breakdowns for players to review asynchronously
- Teams can publish public game analyses with clickable highlights
- Viewers can click timestamps to watch specific plays
- Extension becomes a content creation tool, not just a logging tool

  - [ ] Success/error feedback

- [ ] Add settings for comment customization
  - [ ] Toggle: include opponent scoring events

  - [ ] Not authenticated → trigger OAuth flow

### API Reference
- [YouTube Data API - Comments: insert](https://developers.google.com/youtube/v3/docs/comments/insert)
- [OAuth 2.0 for Chrome Extensions](https://developer.chrome.com/docs/extensions/mv3/tut_oauth/)

### User Flow
1. User clicks "End Game & Generate Report"
2. PDF and CSV are generated (existing flow)
3. New button appears: "Post Timeline to YouTube"
4. Click → OAuth prompt (first time only)
5. Preview modal shows formatted comment
6. User clicks "Confirm & Post"
7. Extension posts comment via YouTube API
8. Success message with link to comment

### Design Decisions to Make
- Should we post as a top-level comment or reply to an existing comment?
- Should we include a link to the PDF report? (requires hosting PDFs somewhere)
- Should we support batch posting (multiple games to a playlist)?
- Should we allow editing the comment text before posting?

## 🔮 v1.2+ - Future Enhancements

### Medium Priority

- **Keyboard shortcuts** — Number keys for quick event logging, arrow keys for undo/redo
- **Autocomplete for comments** — Suggest common phrasings based on past entries
- **Opponent roster tracking** — Full roster for opponent with their own stats
- **Export to coaching platforms** — Hudl (JSON), SportsCode (XML), Google Sheets API

### Lower Priority

- **Cloud sync** — Firebase/Supabase backend for multi-device access
- **Mobile-friendly layout** — Bottom-sheet design for touch devices
- **Video playback controls** — Embed controls in panel (play/pause/speed)
- **Highlight reel generation** — Auto-clip events into a video montage
- **Team collaboration** — Multiple users logging same game, merged timelines

### Research / Experimental

- **Auto-event detection (CV/ML)** — Automatically detect makes/misses, rebounds from video
  - Requires frame extraction, basketball-specific CV model
  - Massive scope increase, separate project
  - Current architecture supports it (events from any source)
