ICON FILES NEEDED
=================

Please create the following icon files in this directory:

- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

These should be basketball-themed icons (e.g., a basketball, clipboard with plays, etc.).

You can use any icon generator tool or create simple placeholder icons:
1. Use an online tool like https://www.favicon-generator.org/
2. Or use ImageMagick: convert -size 128x128 xc:orange -draw "circle 64,64 64,10" icon128.png
3. Or use a design tool like Figma, Canva, etc.

For now, the extension will work without icons, but Chrome may show warnings.
